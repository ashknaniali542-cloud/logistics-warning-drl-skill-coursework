# 科研绘图与网络结构图

## 从问题选择图形

先写[图形任务卡](../assets/figure-brief.md)：读者需要判断什么、使用哪份真实输出、坐标和分母是什么、哪部分最重要、最终版面多宽。参考图用于借鉴视觉语言，不能借用其数据、地理位置、效应量或网络机制。

| 科学问题 | 优先图形 | 必须解释 |
|---|---|---|
| 多模型在同口径下差多少 | 点图、哑铃图、带区间的横向比较 | 绝对值、差值、重复训练/区间来源 |
| 收益与工作负担如何取舍 | 覆盖—核查量曲线、标记预算工作点 | 横纵轴业务含义；离散点非完整最优前沿 |
| 收益何时累积 | 按日累积增益曲线、直接终点标注 | 按订单队列还是实际运行日期、原始单位 |
| 能否满足更长提前量 | 完整提前量覆盖曲线＋差值面板 | 全部阳性分母；零线与正负差异 |
| 参数、仓库或时间条件有何差异 | 分面图、热图、气泡图 | 样本量、变换尺度、组别和权重 |
| 有真实分布与足够样本 | ECDF、箱线/小提琴、必要时山脊图 | 观察单位、原始点或样本数 |
| 输入扰动如何影响 | 延迟响应线、缺失类型点阵 | 冻结模型、扰动幅度、实际误报/覆盖 |
| 概率是否可信 | 校准图、分箱频数、尾部评分 | 概率事件、箱内样本和不确定性 |
| 方法怎样工作 | 总体流程＋真实网络子图＋局部时序 | 训练/推理、冻结/可训练、信息与梯度流 |
| 网络流/空间关系 | 有真实边和坐标才用网络/地图 | 边含义、权重单位、坐标来源 |

雷达图、3D面、极坐标、Sankey不因“图种丰富”自动使用。Sankey需有可解释流量或经验证贡献；神经网络连线不等于测得的重要性。

## 视觉设计原则

画面大方、清楚、有留白，避免密集九宫格和每处填满文字。每图一个主要问题，复杂内容拆图或分面。细线、轻网格、少量标记、端点直接标注、克制填色；图例不要压数据。

可选用蓝—浅青—粉红系列，精确色值见[palette.json](../assets/palette.json)。主要模型用深蓝或中蓝，对照用浅蓝/中性色，成本、负向变化和强调用粉红。每张图通常取2–4个语义主色；十种色值是可用色库，不要求全部出现。淡色用于填充而非小字号文字。以颜色和线型/点型共同编码，检查灰度可辨性。

坐标按数据和比较目的设定。柱形高度一般从零开始；点线图可使用适当范围，但清楚显示刻度，避免夸大差异。比较同一量时尽量同轴；独立量级使用分面并标明范围不同。对数/对称对数变换、气泡面积映射和反向时间轴均写入图注。差值图保留零线和负值。

最终版面才是可读性标准。先确定单栏/通栏宽度，再选字体和面板数。图下注释长时放论文图注，不挤进图内。图与分析同页优先；减少无意义的大边距，同时保留标签呼吸空间。

## 真实神经网络图

先读取模型定义或检查点结构，列出输入维度、层数、每层宽度、激活、归一化、分支、输出与连接。以项目实际结构为准，不从参考图片复制编码器—解码器、注意力或卷积。

可借鉴的视觉形式：层组轻边框、适量堆叠表现模块层次；同一模块内神经元采用同色梯度；连接线半透明且有序，避免全连接线形成黑团。用省略号表达大维度，旁边标真实尺寸。层次和颜色负责解释，不承担虚构“重要性”。

DRL图明确在线网络、目标网络、损失/回报、更新路径、等待/动作输出。预测器冻结与策略可训练用标签区别；推理信息流用实线，训练更新可用虚线。概览图讲模块协作，详细图讲真实网络，二者不重复塞入全部公式。

辅助时长模型或解释模块若单独训练/评价，在图中画出边界。不要通过箭头暗示存在未实现的联合反向传播、调度优化或真实干预反馈。

## 工具和导出

优先沿用用户明确选定的MATLAB、Python或R及现有可运行脚本。可读取nature-figure、Academic Figure Skill与AgentFigureGallery中的相关资源；用户已有参考与后端选择无需重复确认。依赖缺失时采用已可用的同类方案，并说明实际使用工具。

定量结果图使用真实数据和标准绘图库生成，保留源数据与绘图脚本。AI图像生成仅用于合适的机制/概念示意，不负责生成实验数值、区间或统计图。执行时遵循当前可用图像工具要求，逐项核对生成图的文字、连接和网络结构。

按用途导出矢量PDF/SVG和预览PNG，或按期刊要求导出TIFF。MATLAB连接可用时直接调用；绘图任务无需为形式完整而额外建立Simulink仿真。

检查四项：数据与图一致、视觉清晰、统计语义准确、版面可读。重绘后重新查看最终尺寸与实际论文页面；不能仅以脚本执行成功结束。
