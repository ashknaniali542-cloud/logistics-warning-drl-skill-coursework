# 深度学习与强化学习基础：研究选型导读

本节提供通用概念及其在供应链物流应急研究中的用途，不包含课程原件、私人作业或项目结果。算法推导与实现应结合公开原始论文和官方文档核验。

| 知识模块 | 研究中需要理解的机制 | 典型用途与检查点 |
|---|---|---|
| 张量、自动求导与MLP | 非线性函数近似、计算图、反向传播 | 表格状态的价值/策略网络；检查输入维度、梯度和训练/评估模式 |
| 优化器与正则化 | 梯度步长、动量、自适应更新和泛化 | 训练稳定性诊断；区分损失下降与业务目标改善 |
| CNN | 局部结构与权重共享 | 有空间栅格或局部关系的输入；普通表格列不自动具有空间邻接意义 |
| RNN、LSTM、GRU | 隐状态与历史记忆 | 动态库存、事件顺序、延迟信息；检查前缀可见性、隐状态重置与mask |
| 注意力和Transformer | 跨位置关系、位置编码、因果掩码 | 复杂历史或多实体关系；先证明所需信息未被简单状态充分表达 |
| MDP与回报 | 状态、动作、转移、奖励、终止与长期取舍 | 描述应急响应如何影响后续机会与资源状态 |
| 策略梯度 | 用回报更新神经动作分布 | REINFORCE等直接策略学习；关注采样和方差 |
| 值函数方法 | Bellman更新、目标网络、动作价值 | 离散响应/等待选择；检查终端目标和动作约束 |
| Actor–Critic | 神经策略与价值估计的分工 | PPO、连续控制及更复杂策略；核对数据采集与训练方式 |

## 常见概念区分

神经网络承担策略或价值函数近似，并通过序贯目标更新，才构成相应DRL方法。监督训练的预测器可以作为输入模块，但不能单独代表DRL。网络编码器与RL算法是不同设计层次，例如“GRU编码器＋DQN”。

Q值是未来回报估计，不是延误概率。Distributional RL描述回报分布，业务时长模型描述事件持续时间，两者需要各自定义和评价。

同策略与离策略描述经验来源与学习策略的关系；固定离线数据还涉及动作覆盖和分布偏移。把历史表转换为环境接口，不会自动补全未记录的行动后果。

经典方法提供清晰参照。引入注意力、复杂网络或多智能体结构时，说明数据中的相应结构、带来的决策能力，以及通过何种对照验证。
